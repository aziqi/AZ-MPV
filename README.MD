# 🌟 BETTER-MPV

Selamat datang di **BETTER-MPV**! Ini adalah konfigurasi pemutar video tingkat lanjut (berbasis [mpv-lazy](https://github.com/hooke007/mpv_PlayKit) dan MPV Player) yang telah dioptimasi dan dimodifikasi besar-besaran agar sangat mudah digunakan, kaya akan fitur, dan ramah untuk pengguna Indonesia.

Pemutar video ini cocok untuk menonton film resolusi tinggi, anime, dan video lainnya dengan kualitas visual maksimal (menggunakan *Shaders* dan *VapourSynth*) tanpa membuat Anda pusing mengaturnya dari nol.

## ✨ Fitur Unggulan

- **Opsi Aspek Rasio (VLC-Style):** Kini hadir dengan tombol *Aspect Ratio* langsung di antarmuka bawah (UI). Anda bisa dengan cepat merubah rasio video ke `16:9`, `21:9` (Format Bioskop), `4:3`, dsb dengan hasil *letterbox* (bar hitam) yang sempurna, persis seperti di aplikasi VLC!
- **Menu Terjemahan Mudah (Easy Translate):** Fitur otomatis untuk mencari dan menerjemahkan subtitle.
- **Shader Menu Langsung dari UI:** Menyalakan efek peningkatan kualitas gambar (*upscaling*, penajaman warna) dengan sekali klik dari menu grafis.
- **Antarmuka (UI) Modern:** Bar kendali gaya modern (UOSC) yang bersih dan minimalis.
- **Siap Pakai (Portable):** Tinggal ekstrak dan jalankan tanpa perlu instalasi sistem yang rumit!

## 📥 Cara Download & Install

1. Pergi ke halaman [**Releases**](https://github.com/aziqi/BETTER-MPV/releases) di repositori ini.
2. Download file `.zip` versi terbaru (misal: `BETTER-MPV-v1.0.zip`).
3. Ekstrak file zip tersebut di mana saja (misalnya di drive `C:\` atau `D:\`).
4. Jalankan file `mpv.exe` atau `MPV.bat` untuk mulai menonton!

> **Tips:** Anda bisa menjadikan `mpv.exe` sebagai *default player* untuk file `.mkv`, `.mp4`, dan lainnya di Windows Anda.

## ⌨️ Cara Penggunaan (Hotkey Penting)

- **Klik Kiri (Tahan & Geser):** Memindahkan posisi *window* video.
- **Scroll Mouse:** Mengecilkan atau membesarkan volume (atau mencari posisi video).
- **Klik Kanan:** Membuka Menu Utama (UOSC).
- Di bagian tengah bawah layar saat *mouse* diarahkan, Anda akan menemukan deretan tombol kontrol, termasuk tombol **Aspect Ratio**, **Subtitle**, **Audio**, dan **Shader**.
