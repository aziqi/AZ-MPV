# AZ-MPV Project Rules

## Atomic Commits & High-Frequency GitHub Protocol
1. **Always Break Work Into Micro-Commits:** Never group multiple unrelated features or file edits into a single commit.
2. **One Logical Task Per Commit:** Commit every individual script edit, configuration tweak, documentation update, and UI enhancement as its own commit.
3. **Conventional Commit Format:**
   - `feat(...)`: New features or scripts
   - `fix(...)`: Bug fixes or option corrections
   - `docs(...)`: README, FAQ, or guide updates
   - `style(...)`: Visual UI / font / icon adjustments
   - `config(...)`: mpv.conf, uosc.conf, or script-opts changes
   - `refactor(...)`: Code reorganization
4. **Proactive Pushing:** Automatically commit and push each sub-task to GitHub immediately after completion.
